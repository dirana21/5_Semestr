# Лабораторна робота №12. Райдужні таблиці та захист паролів

[Звіт із покроковим прикладом, результатами та скриншотами](./Звіт.md)

У звіті принцип райдужної таблиці показано на умовних позначках. [password_verification.py](./password_verification.py) демонструє створення та перевірку двох записів пароля з різною сіллю.

## Запуск

Відкрий папку лабораторної та виконай:

```powershell
python password_verification.py
```

Програма використовує стандартну бібліотеку Python. Під час кожного запуску вона створює нові випадкові солі, тому числа змінюються, а результати порівнянь залишаються такими самими.
