# Лабораторна робота №10. LSB-стеганографія в PNG

Програма створює тестове зображення, вбудовує в окремі копії текст і JSON та читає їх із збережених PNG. Кожен зразок перевіряється двома способами. Власний алгоритм працює з каналами RGB через Pillow, а бібліотечний використовує Stegano.

[Звіт із покроковим прикладом і результатами](./Звіт.md)

## Запуск

Відкрий цю папку в редакторі. Для відтворення результату у Windows виконай у PowerShell:

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe demo.py
```

| Файл | Призначення |
|---|---|
| [lsb_manual.py](./lsb_manual.py) | Власні функції запису й читання |
| [demo.py](./demo.py) | Створення вхідного PNG, чотири запуски й перевірка |
| [result](./result/) | Вхідне зображення і чотири PNG з вбудованими зразками |
