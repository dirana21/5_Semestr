# Лабораторна робота №9

Протидія кейлогерам засобами Python. Локальний аналіз процесів за назвою й аргументами.

- [Звіт із покроковим поясненням](./Звіт.md)
- [Детектор і графічний інтерфейс](./detector.py)
- [Навчальний процес](./demo_process.py)
- [Автоматичні тести](./test_detector.py)

Запуск із папки лабораторної. Потрібні Python 3.10 або новіший, psutil і Tkinter для віконного режиму.

```bash
python -m pip install -r requirements.txt
python detector.py gui
python detector.py demo
python -m unittest -v
```

У вікні **«Перевірити процеси»** виконує поточне сканування, а **«Навчальний тест із заміром»** запускає імітатор, знаходить його за PID і маркером та показує час. У консолі `python detector.py scan` показує збіги за метаданими. Імітатор лише тримає процес активним кілька секунд. Дані клавіатури у вправі не використовуються.
