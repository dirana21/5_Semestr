У методичній вказівці наведено 7 варіантів, тому номер 8 відповідає першому варіанту: `((8 - 1) % 7) + 1 = 1`.

## Завдання варіанта

Реалізувати клас `BankAccount` для банківського рахунку з атрибутами імені та балансу. Забезпечити злиття рахунків і порівняння за балансом.

## Запуск у PyCharm

1. Відкрити папку лабораторної роботи як проєкт.
2. Відкрити `bank_account.py` і натиснути **Run 'bank_account'**.
3. Відкрити `test_bank_account.py` і натиснути **Run 'Python tests in test_bank_account.py'**.

Зовнішні бібліотеки не потрібні; достатньо Python 3.10 або новішого.
