У методичній вказівці наведено 7 варіантів, тому номер 8 відповідає першому варіанту: `((8 - 1) % 7) + 1 = 1`.

## Завдання варіанта

Реалізувати тему «Бібліотека медіа»: ієрархію `MediaItem → Book, DVD, Magazine` та ітерований клас `Library`. Продемонструвати успадкування, поліморфізм, інкапсуляцію й механізм ітерації.

## Запуск у PyCharm

1. Відкрити папку лабораторної роботи як проєкт.
2. Відкрити `media_library.py` і натиснути **Run 'media_library'**.
3. Відкрити `test_media_library.py` і натиснути **Run 'Python tests in test_media_library.py'**.

Зовнішні бібліотеки не потрібні; достатньо Python 3.10 або новішого.
