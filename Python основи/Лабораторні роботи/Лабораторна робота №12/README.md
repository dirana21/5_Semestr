# Лабораторна робота №12

Вебверсія калькулятора лабораторної №11 на Python CGI. Для номера 8 збережено варіант 2 із вісімковим записом цілих чисел.

[Звіт](./Звіт.md) · [HTML-форма](./index.html) · [CGI-скрипт](./cgi-bin/calculate.py) · [Методична вказівка](./Завдання.pdf)

## Запуск у Windows

Потрібен Python 3.10–3.12 та сусідня папка лабораторної №9 із wheel-файлом. Виконайте команди з каталогу цієї роботи.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install "..\Лабораторна робота №9\dist\levchenko_python_toolkit-1.0.0-py3-none-any.whl"
.\.venv\Scripts\python.exe serve.py
```

Відкрийте [локальну форму](http://127.0.0.1:8000/). Виберіть операцію та введіть числа. Для кореня або прямого вісімкового перетворення потрібне лише A. У PyCharm виберіть інтерпретатор із `.venv` і запустіть `serve.py`.

GitHub відображає звіт і знімки екрана. Для обчислень потрібен запущений CGI-сервер.
