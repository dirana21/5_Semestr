## Вміст папки

- [Звіт](./Звіт.md) — звіт українською мовою з результатами та відповідями на контрольні питання.
- [Програма](./decorators.py) — реалізація декоратора `@log` і приклади його використання.
- [Автоматичні тести](./test_decorators.py) — перевірка функціональності декоратора.
- [Завдання](./Завдання.pdf) — методична вказівка до лабораторної роботи.
- [Скріншоти](./screenshots/) — результати запуску в PyCharm.

## Запуск у PyCharm

1. Відкрити папку лабораторної роботи як проєкт.
2. Відкрити `decorators.py` і натиснути **Run 'decorators'**.
3. Для перевірки тестів відкрити `test_decorators.py` і натиснути **Run 'Unittests in test_decorators'**.

Зовнішні бібліотеки не потрібні; достатньо Python 3.10 або новішого.
