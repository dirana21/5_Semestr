## Завдання

Виконати GET- і POST-запити до REST API в окремих потоках, зберегти отриману інформацію в базі даних SQLite та реалізувати читання збережених записів.

## Вміст папки

- [Звіт](./Звіт.md) — оформлений звіт українською мовою.
- [Програма](./api_sqlite.py) — потоки, HTTP-запити й робота з SQLite.
- [База даних](./api_data.db) — створена програмою база з відповідями API.
- [Автоматичні тести](./test_api_sqlite.py) — 15 тестів без залежності від мережі.
- [Завдання](./Завдання.pdf) — методична вказівка до лабораторної роботи.
- [Скріншоти](./screenshots/) — результати запуску програми й тестів у PyCharm.

## Запуск у PyCharm

1. Відкрити папку лабораторної роботи як проєкт.
2. Відкрити `api_sqlite.py` і натиснути **Run 'api_sqlite'**.
3. Відкрити `test_api_sqlite.py` і натиснути **Run 'Python tests in test_api_sqlite.py'**.

Для демонстраційного запуску потрібне інтернет-з'єднання. Зовнішні бібліотеки не використовуються; достатньо Python 3.10 або новішого.
