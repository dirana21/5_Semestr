**Номер студента:** 8<br>
**Варіант за циклічним розподілом:** 1

У методичній вказівці наведено 7 варіантів, тому номер 8 відповідає першому варіанту: `((8 - 1) % 7) + 1 = 1`.

## Завдання варіанта

Реалізувати контекстний менеджер тимчасової конфігурації `ConfigContext`. Тимчасові значення мають діяти лише всередині блоку `with`, а початковий стан повинен відновлюватися навіть після винятку.

## Запуск у PyCharm

1. Відкрити папку лабораторної роботи як проєкт.
2. Відкрити `config_context.py` і натиснути **Run 'config_context'**.
3. Відкрити `test_config_context.py` і натиснути **Run 'Python tests in test_config_context.py'**.

Зовнішні бібліотеки не потрібні; достатньо Python 3.10 або новішого.
