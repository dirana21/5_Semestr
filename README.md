## Структура матеріалів

- `Лекції` — конспекти, презентації та інші матеріали лекцій.
- `Лабораторні роботи` — завдання, звіти, програмний код і додатки до лабораторних робіт.

Назви файлів рекомендовано починати з номера роботи або лекції, наприклад: `Лекція 01.pdf`, `Лабораторна робота 02.docx`.
