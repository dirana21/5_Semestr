## Результат

Для десяти матриць експертів обчислено попарні відстані Кемені. Медіана та середнє за Кемені збігаються: мінімум досягається для однакової матриці експертів № 4, № 7 і № 8. Значення цільових функцій: `min ΣD = 18`, `min ΣD² = 52`.
