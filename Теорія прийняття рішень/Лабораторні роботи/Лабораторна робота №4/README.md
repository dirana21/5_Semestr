# Лабораторна робота № 4

**Дисципліна:** Теорія прийняття рішень<br>
**Тема:** Використання методу парних порівнянь і методу аналізу ієрархій<br>
**Варіант:** 12<br>
**Мова програмування:** C#<br>
**Виконав:** Левченко Д. В., КН-24-1<br>
**Перевірила:** доцент кафедри Рилова Н. В.

## Результат

Метод аналізу ієрархій застосовано до вибору району для купівлі квартири. За трибальною та дев'ятибальною шкалами найкращою альтернативою стало **Молодіжне**. Усі матриці парних порівнянь мають відношення узгодженості менше `0,1`.
