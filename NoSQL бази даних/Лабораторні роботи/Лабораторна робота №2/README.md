# Лабораторна робота № 2 з NoSQL баз даних

**Тема:** Використання PyMongo. Пошук та фільтрація документів у MongoDB

**Вихідний номер варіанта:** 5

**Примітка:** у завданні немає окремих варіантів, тому робота виконується за спільною умовою.

**Виконав:** Левченко Д. В.

**Перевірив:** Андреєв П. І.

## Результат

Для бази `nosql_lab1_variant5`, створеної в лабораторній роботі № 1, реалізовано 25 запитів через PyMongo. Запити охоплюють:

- оператори порівняння `$eq`, `$ne`, `$gt`, `$gte`, `$lt`, `$lte`, `$in`, `$nin`;
- логічні оператори `$and`, `$or`, `$not`, `$nor`;
- регулярні вирази `$regex`;
- вкладені поля через dot notation;
- масиви, включно з `$all`, `$size` і `$elemMatch`.

Сценарій перевіряє, що кожен запит повертає хоча б один документ. Результати останнього успішного запуску збережено у [`results/lab2_results.json`](./results/lab2_results.json).

## Аналіз індексу

Для запиту до `laboratory_works` за полем `variant` виконано `explain()` до і після створення індексу `variant_1_lab2`.

| Стан | План | Перевірено ключів | Перевірено документів |
|---|---|---:|---:|
| до індексу | `COLLSCAN` | 0 | 10 |
| після індексу | `IXSCAN` + `FETCH` | 4 | 4 |

Індекс усунув повне сканування колекції: сервер переглядає лише чотири ключі та чотири документи, що відповідають умові `variant = 5`.

## Запуск

Потрібні запущений локальний MongoDB Server і база з лабораторної роботи № 1.

```powershell
python -m pip install -r requirements.txt
python scripts/lab2_queries.py --output results/lab2_results.json
```

У разі успіху сценарій виводить JSON з ознакою `"ok": true`, результатами 25 запитів і порівнянням планів виконання.

## Відповіді на контрольні питання

1. **Що таке PyMongo?** Офіційний Python-драйвер для підключення до MongoDB і виконання операцій з базою даних.
2. **Який оператор перевіряє, чи значення більше за вказане?** Оператор `$gt`.
3. **Для чого використовується `$regex`?** Для пошуку рядків за регулярним виразом.
4. **Як звернутися до вкладеного поля?** Через крапкову нотацію, наприклад `curator.teacherId`.
5. **Навіщо створювати індекси?** Щоб зменшити кількість документів, які MongoDB має переглянути під час пошуку, і прискорити запити.
