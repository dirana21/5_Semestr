# Лабораторна робота № 3 з NoSQL баз даних

**Тема:** Агрегація та модифікація документів у MongoDB  
**Вихідний номер варіанта:** 5  
**Виконав:** Левченко Д. В.  
**Перевірив:** Андреєв П. І.  
**Середовище виконання та перевірки:** MongoDB Compass

## Мета

Отримати навички роботи з агрегаційним конвеєром MongoDB для багатоступеневої обробки даних та застосувати методи й атомарні оператори оновлення документів.

## Реалізація

Сценарій [`scripts/lab3_aggregation_updates.py`](./scripts/lab3_aggregation_updates.py) працює з базою `nosql_lab1_variant5`, створеною в ЛР1. Для безпечної демонстрації модифікацій використано окрему колекцію `lab3_updates`; дані попередніх лабораторних не змінюються.

### Покриття агрегації

- етапи: `$match`, `$project`, `$group`, `$unwind`, `$lookup`, `$sort`, `$limit`, `$skip`, `$addFields`, `$count`;
- функції: `$sum`, `$avg`, `$max`, `$min`, `$first`, `$last`;
- п'ять конвеєрів: статистика статусів, навантаження викладачів, популярні технології, огляд дисциплін та підрахунок робіт варіанта 5.

### Покриття оновлень

- методи: `update_one()`, `update_many()`, `replace_one()`;
- оператори: `$set`, `$unset`, `$inc`, `$mul`, `$rename`, `$push`, `$pop`;
- перед кожним запуском навчальні документи ЛР3 відновлюються до початкового стану, тому результат відтворюваний.

## Виконання у середовищі бази даних

1. Підключитися в MongoDB Compass до `mongodb://127.0.0.1:27017`.
2. Відкрити базу `nosql_lab1_variant5` і колекцію `laboratory_works`.
3. На вкладці **Aggregations** виконати конвеєри та перевірити результати.
4. Відкрити колекцію `lab3_updates` і перевірити підсумкові документи у звичайному та табличному режимах.

Для повного відтворення п'яти конвеєрів і семи операцій оновлення використовується сценарій:

```powershell
python scripts/lab3_aggregation_updates.py --output results/lab3_results.json
```

Успішний запуск створює [`results/lab3_results.json`](./results/lab3_results.json) з ознакою `"ok": true`, результатами п'яти агрегацій і журналом семи операцій оновлення.

## Відповіді на контрольні питання

1. **Як називається механізм MongoDB, який обробляє дані через послідовність етапів?** Агрегаційний конвеєр.
2. **Для чого призначений `$group`?** Для групування документів за ключем і обчислення агрегатних показників для кожної групи.
3. **Який оператор збільшує числове поле на задану величину?** `$inc`.
4. **Який метод PyMongo оновлює перший документ, що відповідає фільтру?** `update_one()`.
5. **Який оператор додає новий елемент у кінець масиву?** `$push`.
