> [Повний звіт у форматі GitHub](./Звіт.md)

## Реалізовано

- Cache-Aside для документа MongoDB з TTL 300 секунд;
- Write-Through з одночасним оновленням MongoDB і Redis;
- життєвий цикл тимчасових ключів та перевірка автоматичного видалення;
- читання поточної політики витіснення Redis без зміни конфігурації сервера;
- транзакційний переказ між двома ключами через WATCH/MULTI/EXEC;
- атомарне збільшення лічильника командою INCRBY;
- структурований результат виконання у `results/lab6_results.json`.

## Запуск

Перед запуском мають працювати локальні MongoDB і Redis.

```text
python -m pip install -r requirements.txt
python scripts/lab6_cache_management.py
```

## Структура

- `scripts/lab6_cache_management.py` - реалізація TTL, кеш-патернів, транзакції та атомарного лічильника;
- `results/lab6_results.json` - результат автоматичної перевірки;
- `screenshots/` - знімки MongoDB Compass і Redis Insight без курсора;
- `Звіт_ЛР6_Левченко.docx` - звіт про виконання.
