# Лабораторна робота № 7

Тема: створення графової моделі та завантаження даних у Neo4j.

Варіант: 5  
Виконав: Левченко Д. В.  
Перевірив: Андреєв П. І.

## Реалізовано

- графову модель предметної області попередніх лабораторних робіт;
- вузли `Student`, `Course`, `LaboratoryWork`, `Technology`, `Tool`, `City`;
- зв’язки `STUDIES`, `COMPLETED`, `INCLUDES`, `USES`, `PERFORMED_IN`, `LOCATED_IN`, `EXTENDS`;
- обмеження унікальності для ключових властивостей;
- індекси для назви та статусу лабораторних робіт;
- імпорт семи лабораторних робіт командою `LOAD CSV WITH HEADERS`;
- перевірку структури графа, обмежень, індексів і маршруту між першою та сьомою роботами.

## Запуск

1. Запустити Neo4j Community Edition та переконатися, що Bolt доступний на `localhost:7687`.
2. Скопіювати `data/lab7_labs.csv` у каталог `import` поточного Neo4j.
3. Встановити залежність: `pip install -r requirements.txt`.
4. Виконати: `python scripts/lab7_graph_model.py`.

Результат перевірки зберігається у `results/lab7_results.json`.
