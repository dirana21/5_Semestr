**Тема:** пошук та аналіз вузлів і зв'язків у Neo4j засобами Python.

## Реалізовано

- підключення до Neo4j через офіційний Python-драйвер `neo4j`;
- параметризовані пошукові й аналітичні Cypher-запити;
- аналіз технологій, ступенів вузлів і найкоротшого шляху;
- тестовий набір із 500 вузлів `SearchSample` для вимірювання індексу;
- `EXPLAIN` та `PROFILE` для пошукового запиту;
- порівняння плану й часу виконання до та після індексу;
- автоматичні перевірки з результатом у `results/lab8_results.json`.

## Запуск

Перед запуском мають працювати Neo4j і графова модель ЛБ №7.

```text
python -m pip install -r requirements.txt
python scripts/lab8_neo4j_analysis.py
```
